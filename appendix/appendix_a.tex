Toàn bộ mã nguồn của hệ thống được quản lý trên GitHub, bao gồm các repository sau:

\textbf{Backend Repository:}
\begin{itemize}[noitemsep]
    \item \textbf{URL:} \url{https://github.com/trongvu2003/GlowUp_Web_BE.git}
    \item \textbf{Mô tả:} Mã nguồn backend phát triển bằng Express.js, xử lý API, tích hợp database, VNPay, Ollama chatbot và AI services.
    \item \textbf{Công nghệ:} Node.js, Express.js, Microsoft SQL Server, Qdrant.
\end{itemize}

\textbf{Frontend Repository:}
\begin{itemize}[noitemsep]
    \item \textbf{URL:} \url{https://github.com/Toru2004/GlowUp_Web.git}
    \item \textbf{Mô tả:} Mã nguồn frontend phát triển bằng Nuxt.js 3.4, cung cấp giao diện người dùng cho hệ thống.
    \item \textbf{Công nghệ:} Nuxt.js 3.4, Vue.js, TailwindCSS.
\end{itemize}
