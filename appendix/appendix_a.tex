Toàn bộ mã nguồn của hệ thống được quản lý trên GitHub, bao gồm 
các repository sau:

\textbf{Backend Repository:}
\begin{itemize}[noitemsep]
    \item \textbf{URL:} \url{https://github.com/LeKhang-cn22h/Backend_AR_Clothes.git}
    \item \textbf{Mô tả:} Mã nguồn backend phát triển bằng 
    FastAPI, xử lý API, tích hợp cơ sở dữ liệu, Stripe, 
    Ollama chatbot, pgvector và AI Virtual Try-On (FitDiT).
    \item \textbf{Công nghệ:} Python 3.11, FastAPI, 
    Neon PostgreSQL, Firebase, Cloudinary, Stripe.
\end{itemize}

\textbf{Frontend Repository:}
\begin{itemize}[noitemsep]
    \item \textbf{URL:} \url{https://github.com/Kinn-max/Web_Clothes.git}
    \item \textbf{Mô tả:} Mã nguồn frontend phát triển bằng 
    Nuxt.js 3, cung cấp giao diện người dùng cho hệ thống 
    thương mại điện tử thời trang tích hợp AI Virtual Try-On 
    và AR Try-On.
    \item \textbf{Công nghệ:} Nuxt.js 3.17, Vue.js 3, 
    TailwindCSS, Pinia, Snap Camera Kit, Three.js.
\end{itemize}
