\section{Công cụ hỗ trợ phát triển}

\subsection{Visual Studio Code}
Visual Studio Code (VS Code) là trình soạn thảo mã nguồn miễn phí của Microsoft, hỗ trợ nhiều ngôn ngữ lập trình và có hệ sinh thái extension phong phú, được sử dụng làm môi trường phát triển chính cho đề tài.

\subsection{Git và GitHub}
Git là hệ thống quản lý phiên bản phân tán cho phép theo dõi thay đổi mã nguồn. GitHub là nền tảng lưu trữ mã nguồn trực tuyến sử dụng Git, hỗ trợ cộng tác nhóm và quản lý dự án hiệu quả.

\subsection{Postman}
Postman là công cụ kiểm thử API cho phép gửi các HTTP request và kiểm tra response một cách trực quan, được sử dụng để kiểm thử toàn bộ các endpoint của hệ thống.

\subsection{DBeaver}
DBeaver là công cụ quản lý cơ sở dữ liệu miễn phí, hỗ trợ kết nối và thao tác với nhiều loại cơ sở dữ liệu khác nhau, được sử dụng để quản lý và truy vấn dữ liệu trong quá trình phát triển.
