\section{Công nghệ Backend}

\subsection{Python và FastAPI}
Python là ngôn ngữ lập trình phổ biến, được sử dụng rộng rãi trong phát triển backend. FastAPI là framework hiện đại cho phép xây dựng API nhanh chóng với tính năng tự động tạo tài liệu API và kiểm tra dữ liệu \cite{python_fastapi_official}.

\subsection{RESTful API}
REST (Representational State Transfer) là kiến trúc thiết kế API sử dụng các phương thức HTTP (GET, POST, PUT, DELETE) để thực hiện các thao tác CRUD trên tài nguyên. RESTful API giúp tách biệt frontend và backend, tăng tính linh hoạt và khả năng mở rộng của hệ thống.
